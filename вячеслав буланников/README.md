# Легендарная команда

Консольная игра: команда героев сражается с боссом. Используются наследование, полиморфизм (`special()`) и композиция (`Inventory`).

## Что добавлено
- **Класс `Archer`** (`heroes.py`) — наследует `Hero`. HP 85, атака 15, защита 3, запас стрел 12.
  `special()` — «Град стрел»: 3 выстрела по `attack_power + 5` урона, тратит 3 стрелы. Когда стрелы кончаются, лучник бьёт обычной атакой.
- **Оружие `Эльфийский лук`** (+10 к атаке) и **зелье `Эликсир леса`** (+50 HP) — лежат в `Inventory` лучника.
- **Бонус:** у `Rogue` «Скрытный удар» с шансом 25% становится критическим (двойной урон), через модуль `random`.
- Лучник добавлен в команду в `main.py`.

## Файлы
`heroes.py` — герои, `items.py` — предметы и инвентарь, `boss.py` — босс, `battle.py` — бой, `main.py` — запуск.

## Как запустить
```
python main.py
```
Нужен Python 3.8+. Бой идёт до победы команды или босса.
